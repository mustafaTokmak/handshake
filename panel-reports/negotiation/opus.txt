## Verdict

Yes — but Jev improves the *defended buyer*, not the benchmark, and only if you can show an incremental role over a schema-constrained LLM in the same slot. Build on the negotiation harness, not Breaker. Reject the Breaker idea: it has no counterparty, no scenarios, no metrics, and no baseline, so in 8 hours you'd build all four from zero and then "win" against a threshold you chose yourself. The harness already gives you an adversary, five scenarios, money enforcement, and an offline selftest. That substrate is worth more than sponsor alignment.

## The product: one buyer, two brains, live scoreboard

**Deal Desk** — an autonomous purchasing buyer with a hard split: prose never touches money. Seller text is converted into typed, closed-set evidence with an abstain option; a deterministic Python policy reads only that evidence plus buyer-visible facts (active offer total, BATNA, ceiling, rounds left, whether the market oracle was consulted) and emits continue/counter/accept/walk/check_price.

Three-minute beat sheet:

1. **0:00–0:20** One line: "Agents that negotiate have to read prose and spend money. We let them read prose. We never let them spend from it."
2. **0:20–1:20** One scenario replayed (labeled REPLAY, cached transcript, no live probabilities faked). Split screen: left, a plain prompted buyer; right, Deal Desk. Sidebar shows the typed evidence per turn — `authority_claim`, `finality_claim`, `price_echo`, `cost_justification`, `abstain` — with per-class probabilities rendered as bars, and beneath it the deterministic policy's one-line reason ("finality claim asserted; scripted seller has concessions remaining → counter"). The left agent signs above ceiling; the harness stamps **BLOCKED / attempted_override** on screen. That stamp is your most memorable second.
3. **1:20–2:20** Scoreboard across scenarios × sellers: close rate, regret|closed, value vs BATNA, missed-acceptable-deals, attempted_override count, latency. Deal Desk must beat the prompted agent *and* the deployable deterministic reference, with the privileged scripted-seller-aware baseline labeled as privileged.
4. **2:20–3:00** The honesty beat: "Our earlier forged-audit headline was +38pp. With a tone-matched control it disappeared — 50/60 vs 47/60, p=.73, and the pilot is underpowered, so we can't claim equivalence either. The instrument that killed our own result is the thing we're showing you." Judges remember that. Nobody else will say it.

Real user value is genuine but narrow: procurement/renewal desks want a spender that provably cannot be argued past a ceiling. That's the pitch — not "our agent haggles better."

## Jev's actual role

Jev is the typed-evidence extractor, and the claim must be incremental, not magical. Legitimate: a finite closed question set over supplied state, answered in parallel in one request; per-class probabilities give you a threshold you can tune into an explicit abstain band; abstention makes the policy a total function over classes, so there is no prose path into the money path. Illegitimate and off the table: P(accept), inferring the hidden floor S, multiplying marginals into joint acceptance odds, treating Score as cardinal money utility, or treating confidence as P(correct). If a slide implies any of those, cut it.

## Minimal integration

One function between `seller.respond()` and `buyer.act()`:

`classify_turn(offer.terms, history) -> TypedEvidence` — N independent closed questions, one request, results cached by hash of the prose for replay. Any error or timeout returns `abstain` and records `jev_unavailable` in trial metadata; the policy's abstain branch is conservative (counter, never accept). New spec fingerprint; do not merge with old spec runs. Nothing else in the harness changes.

## Decisive ablation

Same buyer LLM, same scenarios, same seller scripts, same policy code. Four arms:

- **A** prompted buyer reading raw prose (the baseline you must beat)
- **B** deterministic policy, evidence extracted by the same LLM under a strict schema
- **C** deterministic policy, evidence extracted by Jev
- **D** deployable deterministic reference using only buyer-visible facts (plus always-walk and accept-sticker stubs)

A vs (B,C) tests the architecture. **B vs C is the only test of Jev**, and it is the one that decides your talk. If B ≈ C, say so on stage: "the split is what helps; the model in the extractor slot didn't matter at this N." That is a better hackathon result than a quiet omission, and you cannot claim provider calibration transfers to this distribution without measuring it here. Guard the trivial win: a never-accept system must lose on value-vs-BATNA and missed-acceptable-deals, so put both on the scoreboard beside close rate.

## Strongest reason to reject

There is no user on screen, and the opponent is you. You wrote ScriptedSeller, so beating it demonstrates engineering, not a fact about negotiation; a judge can dismiss the whole scoreboard as self-refereed in one sentence. Worse, reprobe4 removed the threat you're defending against: you have no established failure to prevent, so Deal Desk risks being armor for a wound you can't currently show exists. And autonomous procurement agents ship commercially (Pactum), so novelty must be claimed only for the instrument and the split, never for the category. If you can't stomach a demo whose punchline is "our effect died," the copilot framing — same typed evidence, human decides, salary scenario — has more emotional pull and less epistemic exposure, at the cost of a weaker measurable claim in 8 hours.
